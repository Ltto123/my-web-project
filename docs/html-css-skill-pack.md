## 一、DevTools 三板斧

| 操作               | 快捷键                     |
| ------------------ | -------------------------- |
| 打开开发者工具     | `F12`                      |
| 定位页面元素       | `Ctrl+Shift+C`，然后点页面 |
| 强制刷新（清缓存） | `Ctrl+Fn+F5`               |

**样式面板**：看元素匹配的所有 CSS 规则。被覆盖的显示 ~~删除线~~。可以直接改数值实时预览。

**已计算面板**：浏览器最终生效的所有样式，真相之源。盒模型彩图看 margin/border/padding/content。

**用户代理样式表**：浏览器出厂默认样式（`section { display: block; }`），不是你写的 CSS。

## 二、HTML 骨架

| 概念         | 一句话                                                              |
| ------------ | ------------------------------------------------------------------- |
| 页面三件套   | `<header>` 导航栏 + `<main>` 主内容 + `<footer>` 页脚，5 个页面共用 |
| 嵌套关系     | 缩进 = 父子，`<header>` 是父，里面的 `<a>`/`<button>` 是子          |
| 折叠大法     | VS Code 点行号旁小三角折叠代码块，一眼看骨架                        |
| 元素面板速查 | DevTools「元素」面板里鼠标上下移动 → 页面蓝色高亮跟着走             |

## 三、CSS 变量体系

```css
:root {
  --c-primary: #1a7a5a;
} /* 定义：改这里 → 全站变色 */
.button {
  background: var(--c-primary);
} /* 使用 */
```

| 概念     | 一句话                          |
| -------- | ------------------------------- |
| 变量定义 | `--名字: 值;`，写在 `:root` 里  |
| 变量使用 | ** `var(--名字)`，哪里都能用 ** |
| 好处     | 改一行，全站跟着变              |

---

## 四、暗色主题 = 覆盖，不是继承

```
:root              → 默认的变量值（亮色）
body.dark-theme    → 把部分变量重新定义一遍（暗色）
                    没重新定义的变量，沿用 :root 的值
```

**核心句**：同一个变量名，谁的选择器更具体、谁写在后面，谁就赢。

| 概念 | 意思                                       |
| ---- | ------------------------------------------ |
| 继承 | 父元素设的属性，子元素自动拿               |
| 覆盖 | 同一个属性/变量，后来者/更具体者挤掉前面的 |

---

## 五、样式不生效的三条诊断

| 症状                     | 原因                          | 怎么查                                     |
| ------------------------ | ----------------------------- | ------------------------------------------ |
| 样式面板里 ~~删除线~~    | 被更高优先级覆盖              | 看谁覆盖了它                               |
| 没有删除线但颜色不对     | 用了 `var(--xxx)`，变量没改   | 去 `:root` 或 `body.dark-theme` 查变量定义 |
| 元素完全没匹配到这条规则 | HTML 结构不对、class 名写错了 | `Ctrl+Shift+C` 检查选择器                  |

## 六、标准调试 6 步流

```
① Ctrl+Shift+C → 点击想改的元素
② 右侧「样式」面板 → 找到控制效果的那条 CSS
③ 面板里改数值 → 实时看效果 → 调到满意
④ 点规则右边的文件名链接（如 style.css:337）→ 记下行号
⑤ VS Code → Ctrl+G 跳行号 → 改 → Ctrl+S 保存
⑥ Ctrl+Fn+F5 强制刷新 → 验证其他页面 + 亮暗双模式
```

## 七、关键概念速记

| 概念      | 一句话                                             |
| --------- | -------------------------------------------------- |
| 硬编码    | 直接写颜色值 `#1a7a5a`，变量改了它不动             |
| 缓存      | CSS 加载一次，`Ctrl+Fn+F5` 强制重新下载            |
| 版本号    | `style.css?v=5` 让浏览器认为是新文件，用于生产环境 |
| color-mix | 用公式混合颜色，让暗色模式自动跟随主题色           |
