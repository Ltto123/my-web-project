# HTML & CSS 调试能力 —— 一步步学习指导

## Context

Ltto 想获得独立调试本博客 HTML/CSS 的能力——"看到不顺眼的样式 → 定位元素 → 找到 CSS 规则 → 修改 → 验证"，全程不依赖 AI。目前的状态是「看到代码就懵，不知道从哪读起」。

- **浏览器**：Edge（中文版），Win11
- **编辑器**：VS Code
- **教材**：本项目实际的 5 个 HTML 页面 + 1 个 CSS 文件
- **理念**：边改边学，不单独学语法

---

## 总体路线

```
阶段 0: 打开工具箱     (30 min)  → 会用 DevTools「元素」面板
阶段 1: 认识调色盘     (60 min)  → 理解 CSS 变量体系，能改颜色
阶段 2: 看懂骨架       (90 min)  → 理解 5 个页面的 HTML 结构

```

总计约 5-6 小时，建议分 3-5 次完成。我会一步一步带着你做。

## 阶段 0：打开工具箱——掌握浏览器 DevTools

**目标**：能打开 Edge DevTools，用「元素」面板定位任意页面元素，看到它匹配的 CSS 规则和源文件行号。

### 我会带着你做的练习

**第 1 步：打开 DevTools**

Edge（中文版）有 3 种方式打开：
- 按 `F12`
- 按 `Ctrl+Shift+I`
- 在页面上右键 → 选「**检查**」

打开后你会看到 DevTools 窗口，顶部有几个标签页：
- **元素**（Elements）— 我们主要用这个
- 控制台（Console）
- 源代码（Sources）
- 网络（Network）

**第 2 步：用"选择器"定位元素**

- 点「元素」面板左上角的箭头图标（`↖`，鼠标放上去显示"选择元素"），或者按 `Ctrl+Shift+C`
- 把鼠标移到页面上任意一个元素（比如导航栏的「📚 资源库」按钮），会看到蓝色高亮覆盖
- 点击后，DevTools 自动在「元素」面板里高亮对应的 HTML 行
- 右侧「**样式**」面板显示这个元素匹配的所有 CSS 规则

**第 3 步：阅读「样式」面板**

- 每条规则显示：选择器名（如 `.blog-nav .nav-link`）+ 源文件名和行号（如 `style.css:135`）
- 被覆盖的规则会显示 ~~删除线~~
- 可以**在面板里直接改数值**试试效果（比如把 `font-size: 14px` 改成 `20px`）
- 改完后刷新页面就恢复原样——**放心改，不会弄坏任何东西**

**第 4 步：认识「已计算」面板**

- 在「样式」面板旁边有个「**已计算**」标签（Computed）
- 点进去——这是浏览器计算后**最终生效**的所有样式，是排查问题时的"真相之源"
- 里面还有一个彩色嵌套方块图（盒模型图示），后面阶段会用到

**练习任务**：找到以下 3 个东西

1. 导航栏「📖 不背单词」按钮的 CSS 规则在哪里？（文件 + 行号）
2. 页面标题「Ltto的乌托邦」用的是什么颜色？
3. 找到任意一个用了 `var(--c-primary)` 的 CSS 属性

**验收标准**：随便指一个页面元素，能在 30 秒内找到它的 HTML 和对应的 CSS 规则位置。

## 阶段 1：认识调色盘——CSS 变量体系

**目标**：理解 `style.css` 里 `:root` 中定义的 CSS 变量是什么、怎么用，知道改一个变量会影响哪些地方。

### 知识铺垫

CSS 变量就像"全局配色表"。你不用在每个地方写 `#1a7a5a`（绿色），而是写 `var(--c-primary)`。改颜色时只改变量定义处一行，全站自动变色。

### 变量分类速查

| 类别 | 变量名 | 控制什么 |
|------|--------|---------|
| 颜色-背景 | `--c-bg`, `--c-surface` | 页面底色、卡片底色 |
| 颜色-文字 | `--c-text`, `--c-text-2`/`3`/`4` | 文字颜色（从深到浅 4 级） |
| 颜色-主题 | `--c-primary`, `--c-primary-hover` | 主色调（绿）及悬停态 |
| 颜色-功能 | `--c-danger`, `--c-success`, `--c-amber`, `--c-gold` | 危险/成功/警告/金色 |
| 圆角 | `--radius-sm`(8px), `md`(16px), `lg`(20px), `pill`(9999px) | 卡片/按钮的圆角大小 |
| 阴影 | `--shadow-sm` ~ `--shadow-xl` | 卡片阴影深度（4 级） |
| 字体 | `--font`, `--font-heading`, `--font-mono` | 正文/标题/代码字体 |

### 我会带着你做的练习

**练习 1：找到变量定义处**

打开 `frontend/style.css`，看第 4-37 行 `:root { ... }`，这就是所有变量的"老家"。

**练习 2：改主色调实验**
- 把第 12 行 `--c-primary: #1a7a5a;` 临时改成 `--c-primary: #e74c3c;`（红色）
- 保存 → 刷新页面，观察哪些元素变色了（导航栏下划线、发布按钮、链接 etc.）
- **改回去！**（重要习惯：每次试验后复原）

**练习 3：改背景色实验**
- 把 `--c-bg: #faf8f5;` 改成 `--c-bg: #e0e0e0;`
- 观察全站背景变化 → 改回去

**练习 4：理解暗色主题**

看第 39-55 行 `body.dark-theme { ... }`。注意：
- 暗色模式只覆写了**颜色类**变量，没覆写圆角、阴影、字体
- `--c-primary` 在暗色模式下**没有被覆写**，所以亮色暗色用同一个主题色
- 打开暗色模式开关（点「切换主题」），在 DevTools 里看同一个元素的 `--c-bg` 变成什么值

**验收标准**：说得出「我想把全站按钮颜色从绿色改成蓝色，改 style.css 第 12 行」。

## 阶段 2：看懂骨架——5 个页面的 HTML 结构

**目标**：理解 5 个 HTML 页面的共同结构和各自差异，能快速定位某个视觉区域对应的 HTML 代码段。

### 知识铺垫

你的 5 个页面都遵循同一个骨架：

```
┌──────────────────────────────────────┐
│ <header class="blog-header">         │  ← 导航栏（每页一样的位置）
│   Logo + 页面链接 + 登录/主题按钮      │
│ </header>                            │
├──────────────────────────────────────┤
│ <main class="blog-layout">           │  ← 主内容区（每页不一样）
│   <section class="intro-section">    │  ← 标题介绍区
│   <div class="blog-grid">            │  ← 卡片/列表（JS 动态渲染）
│   （搜索栏、表单等，各页面不同）        │
│ </main>                              │
├──────────────────────────────────────┤
│ <footer class="blog-footer">         │  ← 页脚（每页一样）
│ </footer>                            │
├──────────────────────────────────────┤
│ <div id="auth-modal">               │  ← 登录弹窗（每页一样，默认隐藏）
└──────────────────────────────────────┘
```

| 页面 | 文件 | 布局类名 | 主内容区特点 |
|------|------|---------|------------|
| 博客首页 | BLOG.html | `blog-layout` | 发布表单、搜索栏、文章卡片 |
| 个人主页 | personal.html | `blog-layout` | 发布表单（支持图片/文件上传） |
| 资源库 | library.html | **`library-layout`** | 侧边栏 + 分类筛选 + 资源卡片 |
| 中药识别 | HERB.html | `blog-layout` | 拖拽上传、模型选择、识别结果 |
| 不背单词 | VOCAB.html | `blog-layout` | 页内 `<style>` 独立样式 + 单词卡片 |

注意：library.html 是唯一用 `library-layout` 的页面（左侧竖排侧边栏 + 右侧内容区），其他都是 `blog-layout`（纵向排列）。

### 我会带着你做的练习

**练习 1：在 VS Code 里看骨架**

打开 `BLOG.html`，VS Code 左侧行号旁边有小三角箭头，点击可以折叠/展开代码块。把 `<header>`、`<main>`、`<footer>` 都折叠起来，你就能看到最外层骨架。

**练习 2：在 DevTools 里对照**

打开博客首页 → `F12` → 「元素」面板，鼠标在不同 HTML 行上慢慢移动，观察页面上蓝色/橙色的高亮覆盖层。展开/折叠节点（点小三角）来理解嵌套关系。

**练习 3：理解 HTML 的嵌套（父子）关系**

以导航栏为例：

```
<header class="blog-header">           ← 父（最外层）
  <div class="logo">Ltto的乌托邦</div> ← 子1
  <div class="header-actions">        ← 子2
    <a href="/personal">个人主页</a>    ← 孙子（子2的孩子）
    <button id="theme-btn">切换主题</button> ← 孙子
  </div>
</header>
```

在 DevTools 「元素」面板里，缩进越深 = 嵌套越深。把鼠标在不同行移动，页面上的高亮区域会跟着变化。

**练习 4：定位练习（5 道题）**

1. 博客发布表单的 `<textarea>` 在 BLOG.html 的第几行？
2. 资源库的分类筛选栏用了什么 CSS class？
3. 个人主页的图片上传区 `<input>` 在哪个标签里？
4. 中药识别页的拖拽上传区 id 是什么？
5. 不背单词页的词集列表容器 id 是什么？

**验收标准**：看到页面上的任意区域，能在 DevTools 「元素」面板里找到对应的 HTML 代码段。

## 阶段 3：理解优先级——为什么样式"不生效"

**目标**：理解 CSS 选择器优先级，能诊断样式问题的根因。

### 知识铺垫

CSS 的"不生效"通常有 3 个原因，按出现频率排序：

**原因 1：选择器优先级被覆盖**
```css
.nav-link { color: green; }          /* 1 个 class → 低优先级 */
.blog-nav .nav-link { color: red; }  /* 2 个 class → 高优先级，这条赢 */
```
在 DevTools「样式」面板里，被覆盖的规则会显示 ~~删除线~~。

**原因 2：CSS 变量链断了**
```css
.button { background: var(--c-primary); }
/* 如果 :root 里没定义 --c-primary，或者拼错了，就不会生效 */
```

**原因 3：HTML 结构层级不对**
```css
.blog-nav .nav-link { ... }
/* 只对 class="blog-nav" 里面的 class="nav-link" 生效 */
/* 如果 HTML 里 .nav-link 不在 .blog-nav 里面，就不会匹配 */
```

### 优先级速查表（谁分高谁赢）

| 选择器类型 | 示例 | 优先级 | 你的项目里哪里用了 |
|-----------|------|--------|------------------|
| 标签 | `div`, `body` | 最低 | 全局 reset |
| class | `.blog-card` | 中 | 绝大部分样式 |
| 两个 class | `.blog-card:hover` | 较高 | 悬停效果 |
| 更多 class | `.library-main .blog-card` | 更高 | 资源库特殊样式 |
| 内联 style | `<div style="...">` | 最高 | 极少用 |

### 我会带着你做的练习

**练习 1：在 DevTools 里看覆盖**
- 切换到暗色模式，定位导航栏一个链接
- 在「样式」面板观察哪些规则有 ~~删除线~~
- 理解：`body.dark-theme` 的变量定义覆盖了 `:root` 的同名变量

**练习 2：诊断 3 个场景**
- 场景 A：改了 `.toggle-btn { background: red }`，但按钮还是绿色 → 原因？
- 场景 B：给 `.nav-link` 加了 `font-size: 24px`，只有一个链接没变大 → 原因？
- 场景 C：卡片背景在亮色下正常，暗色下没变 → 原因？

**练习 3：在 DevTools 里安全实验**
- 找到博客卡片的 CSS 规则
- 在「样式」面板里**取消勾选**（点规则前面的 ✓）某条规则，看效果
- 在「样式」面板空白处双击，添加新规则：`border: 3px solid red;`
- 刷新页面——全部消失，源文件安全

**练习 4：认识盒模型**
- 选中搜索框，看「已计算」面板里的彩色嵌套方块图
- 从外到内：margin（外边距，橙色）→ border（边框，黄色）→ padding（内边距，绿色）→ content（内容，蓝色）
- 把鼠标放到图示各区域，页面上元素有对应的颜色高亮
- 你的 CSS 第一行有 `* { box-sizing: border-box; }`——这意味着 padding 和 border 内收，不会撑大元素

**验收标准**：样式改了但页面没变化时，能说出是上面 3 种原因的哪一种。

## 阶段 4：实战改样式——你的「毕业设计」

**目标**：在编辑器里改 CSS，刷新浏览器验证，5 个页面亮色+暗色全部检查。

### 任务：把全站主色调从绿色改成蓝色

分 8 步完成，我会带着你走：

**Step 1：明确要改什么**
- `--c-primary: #1a7a5a` → 改成蓝色 `#2563eb`（第 12 行）
- `--c-primary-hover: #145f45` → `#1d4ed8`（第 14 行）
- `--c-primary-light: #ecf7f2` → `#eff6ff`（第 13 行）

**Step 2：在 VS Code 中修改 `frontend/style.css`**

找到 `:root` 块（第 4-37 行），改上面 3 行。保存。

**Step 3：更新 CSS 版本号（重要！否则浏览器可能用缓存）**

当前版本号不统一：

| 文件 | 当前版本 | 需改为 |
|------|---------|--------|
| BLOG.html | `style.css?v=3` | `v=5` |
| personal.html | `style.css?v=3` | `v=5` |
| library.html | `style.css?v=3` | `v=5` |
| HERB.html | `style.css?v=3` | `v=5` |
| VOCAB.html | `style.css?v=4` | `v=5` |

在 VS Code 中按 `Ctrl+Shift+F` 全局搜索 `style.css?v=`，逐个更新。

**Step 4：本地验证—亮色模式**
- 打开博客首页 → `Ctrl+Shift+R` 强制刷新
- 检查：导航栏 active 下划线、发布按钮、链接颜色是否都变蓝

**Step 5：暗色模式验证**
- 点「切换主题」切换暗色模式，确认颜色正常

**Step 6：逐页检查（5 页面 × 2 主题 = 10 个场景）**
- 博客首页 → 打开文章详情弹窗，看链接
- 个人主页 → 发布按钮、点赞按钮
- 资源库 → 分类按钮 active 态、上传按钮
- 中药识别 → 预测按钮
- 不背单词 → 进度条

**Step 7：如果某个地方没变色**
- F12 定位那个元素 → 看「样式」面板
- 是用了 `var(--c-primary)` 还是直接写的 `#1a7a5a`？
- 如果是直接写的颜色值——说明 CSS 里有硬编码，你发现了一个可改进的地方

**Step 8：对比验收**
- 确认 5 页面 × 亮暗 = 10 个场景全部正常

**验收标准**：独立完成改色，全程不需要问我。

## 标准调试流程（6 步——以后每次改样式照着做）

```
① Ctrl+Shift+C → 点击页面上你想改的元素
② 在右侧「样式」面板找到控制该效果的 CSS 属性
③ 在「样式」面板里直接改数值 → 实时看效果 → 调到满意
④ 点击规则右上角的文件名链接（如 style.css:337）→ 记下行号
⑤ 去 VS Code → Ctrl+G 输入行号 → 修改 → Ctrl+S 保存
⑥ Ctrl+Shift+R 强制刷新验证 → 检查其他 4 个页面 → 更新版本号
```
